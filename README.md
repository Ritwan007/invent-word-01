# Invent a Word We Need — entry

One invented English word and its one-line definition. Entry for the
make.fun competition `u-deranalabs-invent-a-word-we-need-17a020e0` — see
https://make.fun/bounty/u-deranalabs-invent-a-word-we-need-17a020e0

## The word

> showerquib (n.) — the perfect reply you think of hours after the argument ended, usually in the shower.

## How it works

`main.py` (Python 3, no dependencies) validates the line against the
competition gate — UTF-8 text, 1–140 characters, not only whitespace —
and writes it, with no trailing newline, to `/output/entry.txt`.

```sh
python3 main.py
```
